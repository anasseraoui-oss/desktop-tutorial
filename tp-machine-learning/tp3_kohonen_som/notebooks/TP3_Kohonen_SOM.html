TP3 : Cartes auto-organisatrices de Kohonen (SOM)¶

Une SOM est un réseau de neurones non supervisé. Elle projette des données de grande dimension sur une grille 2D en conservant la topologie : deux vecteurs proches dans l'espace d'origine tombent sur des nœuds proches de la carte.

Ici, chaque donnée est une couleur RGB (vecteur de dimension 3). Une carte 15×15 apprend à les organiser.

2. Génération des données¶

1000 vecteurs RGB : des sommets du cube {0, 2}³, plus un segment pour les 500 premiers, avec du bruit.

# Generate the data
dataset = np.random.randint(0, 2, size=(1000, 3)).astype(np.float32) * 2
dataset[:500, 1] = np.linspace(0, 2, 500)
dataset[:500, 0] = 0
dataset += np.random.rand(1000, 3) * .7

# Create the colors for the vectors and scale the values to [0, 1]
colors = dataset.copy()
colors -= np.min(colors)
colors /= np.max(colors)

# Slice the dataset to three axes for 3D plotting
reds = dataset[:, 0]
greens = dataset[:, 1]
blues = dataset[:, 2]

# Plot the data
fig = plt.figure(figsize=(10,10))

ax.set_xlabel('Red')

ax.set_zlabel('Blue')

3. Création et entraînement de la SOM (15×15, 3 canaux, 20 itérations)¶

In [3]:
# Create the SOM instance.
som = SOM()
som.create(width=15, height=15, ch=3)

#Fit the map to the dataset using total 20 optimization rounds.
t0 = time.time()
som.fit(dataset, random_sampling=0.5, n_iter=20, dist_method='euclidean')
print("Durée de l'entraînement : %.1f s" % (time.time() - t0))

8. Plans de composantes (R, G, B)¶

In [8]:
#Inspect the map component planes
#Component plane is just slice of the map in the feature (vector component) dimension.
colors = {0 : 'red', 1 : 'green', 2 : 'blue'}

fig, axes = plt.subplots(1, 3, figsize=(15, 5))
for i in range(3):
    cplane = som.get_component_plane(i)
    img = np.zeros(cplane.shape + (3,))
    img[:, :, i] = cplane
    img -= np.min(img)
    img /= np.max(img)
    axes[i].imshow(img)
    axes[i].set_title(f'Component {i} ({colors[i]} in RGB system)')
plt.show()

Conclusion¶

  • La SOM 15×15 a organisé les 1000 couleurs : des couleurs proches occupent des zones voisines de la carte (image RGB, section 5).
  • La U-matrice montre des zones sombres (clusters : les 8 sommets du cube et le segment vert) séparées par des frontières claires.
  • Les plans de composantes montrent comment chaque canal (R, G, B) varie sur la carte.
